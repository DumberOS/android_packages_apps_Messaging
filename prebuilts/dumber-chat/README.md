# dumber.chat Android prebuilts

ARM64 and ARM32 JNI libraries and their matching Kotlin bindings.
Normal ROM/app builds use these files directly; no Cargo or NDK is required.
Keep all files and manifest.json together when updating.

Maintainers: see ../../docs/dumber-chat.md and tools/update-dumber-chat-prebuilts.py.
Rust source is maintained separately in dumber.chat/crates/chat-core.
